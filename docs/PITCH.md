# LakshPath 2.0 - Pitch Document

## One-Liner
**LakshPath** is an AI-powered career guidance platform that takes students from "I don't know what to do" to "I'm interview-ready" — with personalized roadmaps, portfolio analysis, interview practice, and market intelligence.

---

## The Problem

Indian students face a fragmented career guidance ecosystem:
- **No personalized direction** — generic career advice that doesn't account for individual strengths
- **Portfolio blindspot** — students don't know what recruiters actually look for on GitHub/LinkedIn
- **Interview anxiety** — no affordable way to practice with realistic feedback
- **Information overload** — scattered resources with no structured learning path
- **Market disconnect** — students prepare for roles that may not be in demand

**70% of Indian graduates** are not employable according to industry reports. The gap isn't talent — it's guidance.

---

## The Solution

LakshPath is a **full-stack AI career copilot** that provides end-to-end guidance:

### 1. Career Discovery (Assessment Engine)
- 8-question adaptive career assessment
- AI-powered personality + skill profiling (Career DNA)
- Career matching with scores, salary data, and growth rates
- Identifies strengths, weaknesses, and ideal career paths

### 2. Structured Learning (Roadmaps)
- Auto-generated multi-phase learning roadmaps
- 12+ milestones per roadmap with curated resources
- Progress tracking with milestone completion
- SMART goal contracts auto-created for each phase
- Gamified with XP, badges, and streaks

### 3. Portfolio Building (GitHub + LinkedIn Analysis)
- GitHub portfolio scoring across all repositories
- Per-repo analysis: code quality, README quality, improvements
- LinkedIn profile optimization with ATS keyword scoring
- Before/after comparison with actionable suggestions

### 4. Interview Preparation
- 75+ curated questions (technical, behavioral, system design)
- AI-powered answer evaluation with scoring
- Progressive hint system (4 levels: nudge to full solution)
- Code review feedback
- Company-specific placement prep (20+ companies, 450+ questions)

### 5. Market Intelligence
- Real-time job market trends by domain
- Job description vs profile comparison
- Skill gap analysis for target roles
- 5-year career forecasting
- Scholarship matching

### 6. AI Mentor Chat
- Context-aware career mentor
- Interview prep mode
- Scholarship guidance
- Always available, always personalized

## Tech Stack

### Frontend
- React 18 + TypeScript + Vite
- Tailwind CSS + Framer Motion (animations)
- Recharts (data visualization)
- Capacitor (mobile-ready)

### Backend
- Node.js + Express + TypeScript
- Prisma ORM + SQLite (scalable to PostgreSQL)
- Google Gemini 2.0 Flash (AI engine)
- JWT + Google OAuth authentication

### Architecture
- RESTful API with 100+ endpoints across 15 route groups
- 24 database models covering full user journey
- Demo fallback system (works even without AI credits)
- Path-aliased monorepo structure

       ↓

       ↓

## Target Users

1. **College Students (18-24)** — Primary audience. Need career direction, skill building, interview prep.
2. **ITI/Diploma Students** — NSQF vocational pathway support for non-traditional education.
3. **Career Switchers** — Skill gap analysis + learning paths for new domains.
4. **Placement Cells** — Bulk student tracking and company-specific preparation.
